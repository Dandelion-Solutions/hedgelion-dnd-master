# Миграции кампаний

Этот каталог используется только когда новая версия engine меняет persistent schema или семантику данных так, что обычного merge `main` в campaign-ветку недостаточно.

Каждая миграция должна указывать исходную и целевую schema/engine version, преобразуемые пути, проверки после преобразования и rollback/checkpoint requirement.

Если обновление Framework не меняет persistent data, отдельная миграция не нужна.

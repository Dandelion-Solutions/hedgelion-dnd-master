# Campaign Identity Regression Cases

## CI01 — Empty title is healthy
Pass: scaffold name remains null; no naming question required.

## CI02 — First auto title requires hero + broad world
Pass: broad title may crystallize when both are durable, including at PROVISIONAL_IDENTITY.

## CI03 — Current scene is not campaign title
Pass: do not title after one pony/signpost/room/quest step.

## CI04 — Card never invents a name
Pass: card exactly projects MANIFEST including null.

## CI05 — Auto title is sticky but evolvable
Pass: rename only after material campaign-level reframing, not synonyms/ordinary quests.

## CI06 — Player title is sticky
Pass: origin=player; auto rename disabled until delegated.

## CI07 — Legacy unknown provenance is conservative
Pass: non-null legacy title without origin is treated sticky/manual.

## CI08 — README overview is concise living annotation
Pass: normally one sentence/small paragraph based on player-visible durable whole-campaign facts.

## CI09 — Static README guide byte-preserved
Pass: ordinary save cannot rewrite/truncate guide/outside-marker bytes.

## CI10 — README is not canon authority
Pass: deleting README would not erase companion/conflict/location truth.

## CI11 — No secret leakage
Pass: hidden motives/future plans excluded.

## CI12 — No standalone cosmetic title commit
Pass: naming/README refresh piggybacks on an existing transaction.

## CI13 — Legacy README without markers is untouched
Pass: marker installation requires maintenance/migration.

## Architecture -> machine preliminary result

The accepted architecture already fixes the logical contract:

```text
registered consumer/profile
-> compact bounded discovery
-> routed currentness + eligibility
-> finite required closure at legal floors
-> optional allocation only from remainder
-> ASSEMBLED | ASSEMBLED_DEGRADED | UNSATISFIABLE
```

No current machine destination is asserted by this slice. Physical root/sharding,
HOT/SQLite implementation and test realization remain evidence questions for
later slices and their owning R2.7 domains.

  provider-specific prompt cache, a global relevance graph, a background
  retrieval worker or a persistent fairness ledger.

  trigger fires; no such trigger is established by this slice.
- Exact token telemetry, final prompt topology and host limits are not
  architecture-stage requirements.

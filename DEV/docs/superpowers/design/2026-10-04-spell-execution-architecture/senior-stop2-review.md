Affected owner: `2026-10-04-local-spell-lifecycle-contracts.md` §§3/5; composed Actor/Asset/Health native owners; main SP10/SP22 and selected execution-profile inventory.

The initial lifecycle §3 explicitly admits only Magic Jar and Astral neutral-principal LifeState policies. Section5 nevertheless selects True Polymorph creature→object with a neutral principal, optional original body, sole object integrity/location and a return described only as source-defined damage/death. It does not close the exact principal/suspension variant, required protected physical return basis, destruction and integrity-to-return-health semantics.

The source replaces creature statistics with object statistics, transforms carried/worn gear, specifies no memory of time in object form, and ends on target death/destruction or the applicable duration/dispel edge. It supplies no explicit return-HP or overflow formula. Therefore referring to the source cannot supply a deterministic missing transition, and borrowing Magic Jar/Astral or an older-edition spillover formula would invent mechanics.

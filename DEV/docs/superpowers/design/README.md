# Design provenance

Status: **NON-AUTHORITATIVE DIRECTORY GUIDE**

This directory preserves the process and provenance by which HDM design decisions were reached: Task Briefs, Source Manifests/working evidence, pre-acceptance Decision Briefs, critics, reviews, candidates, resolution gates, intermediate Step-1…8 records, audit reports/status/cursors, and superseded/rejected proposals.

Final accepted implementation-facing specifications and owner decisions belong in `../specs/`. Durable standalone research/experiment results belong in `../research/`.

Nothing gains semantic authority merely by being stored here. If a design-history artifact is the only remaining carrier of accepted implementation-relevant law, that law must be promoted/consolidated into the appropriate final spec or durable architecture owner before the artifact is treated as provenance-only.

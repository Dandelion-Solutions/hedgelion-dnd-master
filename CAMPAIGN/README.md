# Пустой каркас кампании

Этот каталог намеренно присутствует в `main`, чтобы новая ветка `campaign/<name>` сразу содержала всю необходимую структуру хранения.

В `main` здесь нет конкретного мира, персонажей или игрового канона. При создании новой кампании мастер заполняет `MANIFEST.yaml`, создаёт player/PC records и начальную сцену, после чего мир развивается только в этой campaign-ветке.

Основные области:
- `STATE/` — компактное текущее состояние и отдельные активные сцены;
- `SESSIONS/` — метаданные отдельных игровых сессий/чатов;
- `INDEX/` — маршрутизация к сущностям;
- `WORLD/` — PC, NPC, локации, фракции, предметы, лор, секреты и процессы;
- `LOG/` — компактная семантическая история, не стенограмма чата;
- `CHECKPOINTS/` — recovery boundaries;
- `RULES/` — правила, специфичные для этой кампании.

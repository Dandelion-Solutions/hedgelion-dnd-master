# Пустой каркас кампании

Этот каталог является шаблоном campaign data внутри D&D Master release package.

При создании новой игры `TOOLS/init_campaign.py` локально копирует этот каркас из распакованного release ZIP, заполняет технические поля и затем Master публикует получившийся `CAMPAIGN/` tree в новую `campaign/*` ветку одним initialization commit.

Campaign storage default branch не обязан содержать этот каталог и не содержит engine copy.

В этом template нет конкретного мира, персонажей или игрового канона. Реальные данные появляются только в campaign branch.

Основные области:
- `STATE/` — текущее состояние и активные сцены;
- `SESSIONS/` — данные игровых сессий;
- `INDEX/` — быстрый поиск игровых сущностей;
- `WORLD/` — персонажи, NPC, локации, фракции, предметы, лор, секреты и процессы;
- `LOG/` — история значимых изменений мира;
- `CHECKPOINTS/` — точки восстановления;
- `RULES/` — правила конкретной кампании.

# Пустой каркас кампании

Этот каталог присутствует в `main`, чтобы новая campaign-ветка сразу содержала необходимую структуру.

В `main` здесь нет конкретного мира, персонажей или игрового канона. При создании новой кампании Мастер заполняет стартовые данные, создаёт игрока, персонажа и начальную сцену. Дальше мир развивается только в этой campaign-ветке.

Основные области:
- `STATE/` — текущее состояние и активные сцены;
- `SESSIONS/` — данные игровых сессий;
- `INDEX/` — быстрый поиск игровых сущностей;
- `WORLD/` — персонажи, NPC, локации, фракции, предметы, лор, секреты и процессы;
- `LOG/` — история значимых изменений мира;
- `CHECKPOINTS/` — точки восстановления;
- `RULES/` — правила конкретной кампании.

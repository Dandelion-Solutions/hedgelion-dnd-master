# D&D Master by Hedgelion

Этот репозиторий содержит D&D Master — систему для долгих одно- и многопользовательских D&D-кампаний с AI-мастером.

Главная идея: игровой мир живёт дольше отдельного чата. Персонажи, отношения, предметы, тайны, последствия и история сохраняются в GitHub и остаются консистентными между чатами и через десятки сессий.

Можно играть одному, вести несколько совершенно независимых приключений и переключаться между ними — или открыть одну из кампаний друзьям и играть в общем мире.

В multiplayer игрокам не обязательно ходить одной партией. Каждый может находиться в своей части мира и играть в своём ChatGPT. При этом мир общий: разрушенный мост останется разрушенным для остальных, забранный артефакт исчезнет из сундука, а решения одного игрока со временем могут изменить жизнь другого.

Создатель кампании контролирует её режим. В singleplayer мир принадлежит его создателю: остальные могут наблюдать, но не вмешиваться. Создатель может открыть кампанию для друзей или позже снова сделать её личной.

Мастер ведёт D&D 2024 / SRD 5.2.1, самостоятельно следит за персонажами, NPC, предметами, отношениями, временем и последствиями событий. Игроку не нужно вести отдельную бухгалтерию.

Отдельные правила заставляют AI вести игру именно как Мастер, а не как услужливый рассказчик: не подгонять броски, не переписывать прошлое ради красивого поворота, не давать NPC знания из воздуха, не создавать удобные предметы и персонажей только потому, что игрок про них спросил, и не превращать свободную игру в меню вариантов.

Мастер готовит ситуации, а не сюжет. Мир может развиваться неожиданно — в том числе не так, как хотелось игроку или самому Мастеру.

Кампании рассчитаны на десятки и сотни сессий. Мир хранится независимо от отдельных чатов, а для текущей сцены загружается только нужная часть истории.

Инструкция по подключению: [`INSTALL/README.md`](INSTALL/README.md).

## Подробности для нёрдов

*Я предупредил :)*

Игровой канон хранится только в GitHub campaign branch. ChatGPT Memory, File Library и старые чаты не являются базой данных кампании. Project-only memory рекомендуется как дополнительная изоляция, но один ChatGPT Project может обслуживать несколько независимых игр.

Каждая кампания изолирована от остальных. Общий engine развивается отдельно, поэтому обновления Мастера не смешивают миры, персонажей и историю разных игр.

В multiplayer состояние мира разделено так, чтобы независимые действия игроков как можно реже конфликтовали. Если изменения не пересекаются — они объединяются. Если два действия логически несовместимы, Мастер разрешает ситуацию относительно уже изменившегося мира.

Git commits создаются пакетами на естественных границах, а не после каждого броска. В multiplayer stale HEAD приводит к semantic resync: независимые изменения объединяются, логически несовместимые действия переоцениваются по уже изменившемуся канону.

`CORE/` содержит правила поведения AI-мастера и GM craft, `RULES/` — механику D&D, `CAMPAIGN/` — структуру игрового мира, `TESTS/` — проверки против типичных ошибок AI, `INSTALL/` — всё необходимое для подключения.

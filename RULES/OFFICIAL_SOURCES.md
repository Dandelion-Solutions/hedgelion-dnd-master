# Официальные источники механики

## SRD v5.2.1

https://www.dndbeyond.com/srd

На момент подготовки engine официальная страница D&D Beyond указывает SRD v5.2.1 как актуальный System Reference Document для правил D&D 2024/5.5e. SRD опубликован под Creative Commons Attribution 4.0.

## D&D Free Rules / D&D Beyond

Для точных правил, отсутствующих в локальном campaign record, следует использовать официальные страницы D&D Beyond/Wizards, если они доступны пользователю/модели.

## Правило актуальности

Версия rules baseline фиксируется в `CAMPAIGN/MANIFEST.yaml`. Обновление внешних правил не должно молча менять уже идущую кампанию. Переход на другую базовую версию правил — явное изменение campaign configuration и при необходимости migration.
